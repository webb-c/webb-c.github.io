How this site works

Every rule here is a sentence built from blocks: a subject, the verb is, and a property. Push the blocks and the sentence changes — and with it, what is true.

The same board sits at the top of About, Publications and Talks, each with its own puzzle and the same five gates, so you can walk from page to page without leaving the board. The blog is plain reading.

subjectisproperty

Gates never need solving — only the content on each board does.

Rather just read? “Hide puzzles” under any board hides them on every page; the menu at the top goes to the same places.
